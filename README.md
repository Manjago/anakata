# anakata

Однопользовательская текстовая игра для мессенджеров. Игрок ходит по
N-мерному лабиринту и собирает буквы, из которых нужно составить слово.

Подробности — в [DESIGN.md](DESIGN.md).

## Требования

- Java 25
- Maven 3.9+

## Сборка и тесты

```bash
mvn test
```

## Запуск консоли

Консоль — инструмент администратора (не интерфейс игрока): собрать и поиграть
можно так:

```bash
./run.sh
```

Скрипт компилирует проект и запускает цикл. Параметры уровня консоль спросит при
старте; пустое поле берёт значение по умолчанию.

| Поле          | Формат                                  | По умолчанию       |
|---------------|-----------------------------------------|--------------------|
| Размеры       | числа через пробел, от 2 до 4 чисел      | `6 6` (2D)         |
| Сид           | целое число                              | случайный          |
| Ориентиры     | целое число не меньше 1                  | `5`                |

Размерность задаёт число чисел: `6 6` — 2D, `5 5 5` — 3D, `4 4 4 4` — 4D.
Непонятое поле консоль переспрашивает; размеры ограничены консольным потолком
клеток, чтобы опечатка не уронила старт.

Шпаргалку можно показать и без запуска игры:

```bash
./run.sh --help
```

В игре ходят каноническими словами (`север`, `юг`, `вверх`, `ана`, …) или их
латинскими алиасами (`n`, `s`, `u`, `a`, …); `помощь` (`help`, `?`) печатает
подсказку, `выход` (`exit`, `q`) завершает игру. Выход работает и на этапе
расспроса параметров, не только в игре.
